How to play CD Player
CD Player FX — visual preview
by @buyorbealoser
• Drag the waveform: scratch / scrub
• Shift + drag: A–B repeat zone (Esc clears)
• Right-click / hold F / long-press: freeze stutter (height = length)
• 1–8 or the pads: set / jump to cue points (Shift / right-click = clear)
• Hold ◀◀ ▶▶: audible rewind / fast-forward · Q reverse
• Z X C V B A H W T: toggle effects · K key lock
• E effects · G equalizer · P presets · S next skin
• R shuffle · 0 reset · wheel zoom · drop a file to load
